## 二、单项指标评分规则（0-10分）

### 2.1 规模与市场地位

**指标1：营业收入（亿元）**
- 评分基准：行业均值或对标企业均值
- 评分公式：`score = min(10, max(0, 5 + (本企业营收 - 行业均值) / 行业均值 * 5))`
- 示例：行业均值50亿，本企业60亿 → score = 5 + (60-50)/50*5 = 6.0分

**指标2：磷酸铁锂产量（吨）**
- 评分公式：`score = min(10, max(0, 5 + (本企业产量 - 行业均值) / 行业均值 * 5))`

---

### 2.2 盈利质量

**指标1：毛利率（%）**
- 评分基准：行业均值
- 评分公式：`score = min(10, max(0, 5 + (本企业毛利率 - 行业均值) / 5 * 5))`
- 示例：行业均值15%，本企业18% → score = 5 + (18-15)/5*5 = 8.0分

**指标2：净利率（%）**
- 评分公式：`score = min(10, max(0, 5 + (本企业净利率 - 行业均值) / 3 * 5))`

---

### 2.3 成本与效率（反向指标：越低越好）

**指标1：单吨生产成本（万元/吨）**
- 评分公式：`score = min(10, max(0, 5 + (行业均值 - 本企业成本) / 行业均值 * 5))`
- 示例：行业均值0.90万元/吨，本企业0.85 → score = 5 + (0.90-0.85)/0.90*5 = 7.8分

**指标2：期间费用率（%）**
- 评分公式：`score = min(10, max(0, 5 + (行业均值 - 本企业费用率) / 行业均值 * 5))`

---

### 2.4 运营与财务健康

**指标1：应收账款周转天数（天）**（反向：越低越好）
- 评分公式：`score = min(10, max(0, 5 + (行业均值 - 本企业天数) / 行业均值 * 5))`

**指标2：资产负债率（%）**（反向：越低越好，但需考虑行业特性）
- 评分公式：`score = min(10, max(0, 5 + (行业均值 - 本企业负债率) / 20 * 5))`
- 注：负债率过高或过低都不好，可设置最优区间60-65%

---

### 2.5 成长潜力

**指标1：营收同比增长率（%）**
- 评分公式：`score = min(10, max(0, 5 + (本企业增长率 - 行业均值) / 10 * 5))`
- 示例：行业均值20%，本企业25% → score = 5 + (25-20)/10*5 = 7.5分

**指标2：研发费用率（%）**
- 评分公式：`score = min(10, max(0, 5 + (本企业研发费用率 - 行业均值) / 2 * 5))`

---

## 三、维度得分计算

每个维度得分 = (指标1得分 + 指标2得分) / 2

示例：
- 规模与市场地位 = (营业收入得分 + 产量得分) / 2
