# 六维雷达图评分标准（2026-06-04 制定）

> 适用：龙蟠集团旗下所有事业部（9BU）
> 制定日期：2026-06-04 | 版本：v1.0 | 状态：正式启用

---

## 一、总原则

1. **dims 综合分（0-100）和 kpis 子评分（0-10）均由公式自动计算，不手动填入。**
2. 数据来源：各BU月报PDF → 对比表原始数据 → 自动计算 → 填入 BUS_DATA。
3. **今后评分标准不再变化**，每个BU均按本标准执行。

---

## 二、指标分类与达成率公式

### 2.1 指标类型

| 类型 | 判断规则 | 达成率公式 |
|------|----------|------------|
| 收益/数量类 | 名称含"收入""毛利""销量""产出""交付"等 | 达成率 = actual / target |
| 成本/费用类 | 名称含"成本""费用" | 达成率 = target / actual（越低越好） |
| 约束/事件类 | 名称含"事故""纠纷""投诉""问题" | 实际=0 → 达成率=1.0（满分）；每发生1次 → -0.1 递减 |
| 比例/率类 | 名称含"率""占比""覆盖率" | 达成率 = actual / target（可直接比较） |
| 环比类（无目标） | MoM格式，无 target 字段 | 上月实际=隐含目标：达成率 = curr / prev（越高越好） |

### 2.2 达成率换算为得分（0-10分）

```
kpi_score = min(10, 达成率 × 10)
```

即：达成率 100% = 10分，达成率 90% = 9分，达成率 120%+ = 10分（封顶）。

成本类指标（越低越好）：达成率 = target / actual，actual < target → 达成率 > 1 → 得分10分。

约束/事件类指标（越低越好）：实际=0 → 达成率=1.0 → 得分10分；每发生1次 → 达成率 -0.1。

## 三、各维度计算规则

### 3.1 D1 战略执行力

**数据来源**：`BU_DATA[buId]._kpiComparison.items`（7项核心KPI）

**kpis 计算**（4个子KPI）：

| 子KPI | 对应指标 | 计算方式 |
|-------|----------|----------|
| KPI目标达成率 | 7项核心KPI综合达成率 | 7项达成率简单平均 |
| 战略协同度 | 收入挑战目标达成率 | actual / target × 10 |
| 项目里程碑完成率 | 产品一次合格率 | actual / target × 10 |
| 资源配置效率 | 回款挑战目标达成率 | actual / target × 10 |

**dims 计算**：`dims.d1 = kpis.d1 四项均值 × 10`

> 说明：D1的4个子KPI无法从7项核心KPI严格一一对应，以上映射关系为当前最优近似。

### 3.2 D2 经营效益

**数据来源**：`BU_DATA[buId]._dimComparison_d2.items`（4项产品指标）

**kpis 计算**（4项）：直接取 actual / target × 10（成本类取倒数）

**dims 计算**：`dims.d2 = kpis.d2 四项均值 × 10`

### 3.3 D3 运营效率

**数据来源**：`BU_DATA[buId]._dimComparison_d3.items`（4项生产指标）

**kpis 计算**：同D2

**dims 计算**：`dims.d3 = kpis.d3 四项均值 × 10`

### 3.4 D4 技术创新力

**数据来源**：`BU_DATA[buId]._dimComparison_d4.items`（MoM格式）

**kpis 计算**（无target，用MoM隐含目标）：

```
达成率 = curr / prev
kpi_score = min(10, 达成率 × 10)
```

但部分指标为"越多越好"（课题数、技改项），部分为"越少越好"（MCU降本额为绝对值，需结合目标）。

**dims 计算**：`dims.d4 = kpis.d4 四项均值 × 10`

### 3.5 D5 风险合规

**数据来源**：`BU_DATA[buId]._dimComparison_d5.items`（MoM格式）

**kpis 计算**：

| 子KPI | 类型 | 达成率公式 |
|-------|------|------------|
| 安全事故率 | 约束类 | 实际=0 → 10分；每1次 → -1分 |
| 隐患整改率 | 比例类 | curr / prev（越高越好） |
| 内控执行率 | 比例类 | curr / prev（需从PDF找数据） |
| 应急演练 | 事件类 | 实际 ≥ 目标 → 10分；否则按比例 |

### 3.6 D6 组织活力

**数据来源**：`BU_DATA[buId]._dimComparison_d6.items`（MoM格式）

**kpis 计算**：

| 子KPI | 类型 | 达成率公式 |
|-------|------|------------|
| 核心人才保留率 | 比例类 | curr / prev（需从PDF找数据） |
| 人均营收 | 收益类 | curr / prev（越高越好） |
| 培训完成率 | 比例类 | curr人次 / 目标人次（需从PDF找目标） |
| 管理层执行力 | 定性类 | AI立项数/荣誉数/IATF减少数综合评估 |

## 四、数据结构要求

每个BU的 BUS_DATA 必须包含以下原始数据（否则无法自动计算）：

```javascript
sdmd: {
    // D1: 7项核心KPI（预算/目标/实际）
    _kpiComparison: {
        items: [
            { name:'收入(万元)', budget:数值, target:数值, actual:数值, unit:'万元' },
            // ... 共7项
        ]
    },
    // D2-D6: 各维度4项对比数据（预算/目标/实际，或MoM）
    _dimComparison_d2: { items: [{ name, budget, target, actual, unit }, ...] },
    _dimComparison_d3: { items: [...] },
    _dimComparison_d4: { format:'mom', items: [{ name, prev, curr, unit }, ...] },
    _dimComparison_d5: { format:'mom', items: [...] },
    _dimComparison_d6: { format:'mom', items: [...] },
}
```

## 六、评分标准执行说明

1. **数据优先原则**：所有评分必须基于PDF原始数据计算，禁止凭空估算。
2. **MoM特殊处理**：prev为0或curr为prev同值的指标，用文字描述代替公式，在评分标准文档中记录处理方式。
3. **成本类指标**：名称含"成本""费用"，达成率 = target / actual。
4. **封顶规则**：kpi_score 上限10分，超出按10分计。
5. **dims误差容忍**：自动计算dims与kpis均值的误差允许±5分，超出时须检查原始数据是否有误。
6. **数据溯源**：每个BU填入数据时，须在BUS_DATA注释中写明数据来源章节（如"计划PDF 3.1节"）。
