# 六维经营健康度评分标准体系

> 版本：v1.0 · 2026-07-04
> 目的：为各事业部六维评分提供客观、可追溯的评估依据

---

## 一、评分原则

1. **数据驱动**：评分基于实际 KPI 数据，禁止凭空打分
2. **目标对比**：优先使用"实际 vs 目标"达成率，次选"当期 vs 上期"环比
3. **透明可查**：每期评分须在 JSON 数据文件中附上原始 KPI 依据
4. **季度校准**：每季度末对评分标准做一次复盘修正

---

## 二、评分维度定义

| 维度 | 名称 | 含义 | 评分依据类型 |
|------|------|------|-------------|
| d1 | 战略执行力 / 核心KPI | 收入、利润等核心财务指标达成 | 达成率（实际/预算） |
| d2 | 经营效益 | 主营产品的销售与盈利能力 | 达成率 or 同比/环比 |
| d3 | 运营效率 | 生产、交付、成本等运营水平 | 环比 or 达标率 |
| d4 | 技术创新力 | 研发、新产品、技术改进 | 项目数量 or 环比 |
| d5 | 风险合规 | 质量、安全、环保、合规 | 达标率（多为100%基准） |
| d6 | 组织活力 | 数字化、人才、AI应用 | 项目数量 or 环比 |

---

## 三、各维度评分参考标准

### d1 战略执行力 / 核心KPI

**通用指标**：收入达成率、利润达成率、成本控制率、回款率

| 达成率范围 | 评分参考 | 说明 |
|-----------|---------|------|
| ≥ 100% | 85–100 | 超额完成 |
| 95%–99% | 75–84 | 接近目标 |
| 85%–94% | 60–74 | 基本完成 |
| 70%–84% | 40–59 | 差距较大 |
| < 70% | 0–39 | 严重不达标 |

**评分计算**：`d1 = round(mean([收入达成率, 利润达成率, 成本控制率, 回款率]) × 权重)`

---

### d2 经营效益

**各BU专属指标**（见第四章），核心看主营产品销量和盈利能力。

| 指标类型 | 评分逻辑 |
|---------|---------|
| 有预算目标 | 达成率 = 实际/目标 × 100 |
| 无预算但有上期 | 变化率 = (实际-上期)/上期 × 100，变化>0 则加分 |
| 仅有分类数据 | 取各产品达成率的平均值 |

---

### d3 运营效率

**核心指标**：产能利用率、一次合格率、加工成本、准时交付率

| 指标类型 | 评分逻辑 |
|---------|---------|
| 产能利用率 | ≥ 100% = 100分，每低1%扣1分 |
| 一次合格率 | ≥ 99% = 100分，每低0.1%扣2分 |
| 准时交付率 | ≥ 98% = 100分，每低1%扣3分 |
| 加工成本 | 环比降低 = 加分，升高 = 扣分 |

---

### d4 技术创新力

**核心指标**：在研课题数、新产品数、OEM认证、技术降本项目

| 指标类型 | 评分逻辑 |
|---------|---------|
| 新产品/配方数 | 环比增加 = 加分，有突破性产品额外加分 |
| 在研项目数 | 数量越多且进度正常 = 加分 |
| 专利数 | 发明专利权重高于实用新型 |
| 技术降本 | 实际降本金额越大 = 加分 |

---

### d5 风险合规

**基准原则**：d5 以 100 分为满分，事件发生即扣分。

| 指标类型 | 基准分 | 扣分规则 |
|---------|-------|---------|
| 质量合格率 | 100 | 每降低0.1%扣3分 |
| 安全隐患整改率 | 100 | 每降低1%扣5分 |
| 安全事故 | 100 | 每起一般事故扣10分，重大事故扣30分 |
| 客户质量投诉 | 100 | 每起投诉扣3分 |
| 廉洁举报 | 100 | 有经查实的问题则扣分 |

---

### d6 组织活力

**核心指标**：AI项目立项、数字化项目、新客户开发、人才引进

| 指标类型 | 评分逻辑 |
|---------|---------|
| AI/数字化项目立项 | 环比增加 = 加分 |
| 新客户开发 | 新增有效客户数越多 = 加分 |
| 人才引进 | 关键岗位到岗率 |
| 企业荣誉/认证 | 有新增认证/荣誉额外加分 |

## 五、综合评分计算

各 BU 有差异化权重（见 `bu_weights.json`），综合评分公式：

```
综合评分 = Σ(d_i × weight_i) / 100
```

权重示例（常州锂源）：

| 维度 | 权重 |
|------|------|
| d1 战略执行力 | 30% |
| d2 经营效益 | 25% |
| d3 运营效率 | 15% |
| d4 技术创新力 | 10% |
| d5 风险合规 | 10% |
| d6 组织活力 | 10% |

各 BU 权重标准详见 `bu_weights.json`。

## 六、评分操作流程

### 每次更新月度数据时：

1. **收集原始数据**：从月度总结 PDF 中提取各维度 KPI 实际值
2. **对照标准打分**：按本章第三、四节的规则计算 d1–d6
3. **填入 JSON 文件**：写入 `radar_data/{bu_id}/{YYYY-MM}.json` 的 `dims` 字段
4. **附上 KPI 依据**：将原始 KPI 数据填入 `_kpiComparison` 和 `_dimComparison_*` 字段
5. **运行脚本**：`python update_radar.py {bu_id} {YYYY-MM}`

### JSON 文件必填字段：

```json
{
  "month": "2026-07",
  "source": "xxx事业部7月总结.pdf",
  "dims": {
    "d1": 85, "d2": 78, "d3": 92, "d4": 65, "d5": 100, "d6": 70
  },
  "_kpiComparison": {
    "title": "7月核心KPI达成率",
    "items": [
      {"name": "收入达成率", "budget": 100000, "actual": 98000, "unit": "万元"}
    ]
  },
  "_dimComparison_d2": {
    "title": "7月经营效益",
    "format": "mom",
    "items": [
      {"name": "产品A销量", "prev": 100, "curr": 110, "unit": "吨"}
    ]
  }
}
```

## 七、注意事项

- d5 风险合规以 100 为满分基准，有问题事件须如实扣分，不可人情分
- 新BU上线时若无历史数据，可先按"目标达成率"打一次，后续环比调整
- 跨BU横向比较时注意：d2 经营效益指标因业务性质不同，不可直接对比
- 评分存疑时，优先保证数据真实性，宁可低分不要虚高
