# 法恩莱特事业部 - 六维雷达评分标准

> 版本：v1.0（2026-06-10 制定）| 状态：正式启用
> 适用范围：法恩莱特事业部（电解液）

---

## 一、总原则

1. **D1 核心KPI = avg(D2..D6)**：核心经营指标是其他五个维度的综合均值。当核心经营差时，所有维度联动被拉低。
2. **总分公式**：`总分 = √D1 + avg(D2..D6)/2`
   - 当D1=12时，√D1=3.5，辅助均值77，辅助贡献38.5，总分=42
   - 当D1满分时，√D1满分，辅助维度不受限
3. **各维度子KPI独立计算**：D2-D6各自按真实数据计算，不受其他维度直接控制
4. **所有得分上限100分**：达成率超过100%按100分计

---

## 二、指标分类与计算方式

| 指标类型 | 计算公式 | 说明 |
|---------|---------|------|
| 销量/收入达成率 | actual / budget × 100 | 目标↑，越高越好 |
| 毛利率（实际为负） | 直接用实际百分比 | 负分，如-2.7%→-2.7分 |
| 净利率（实际为负） | actual / budget × 100 | 亏损时=0分 |
| 期间费用率 | actual / budget × 100 | 越低越好 |
| 现金流达成率 | actual / budget × 100 | 目标↑ |
| 回款率 | 实际回款率% | 直接用 |
| 降本率达标 | actual / target × 100 | target=6%（月度目标） |
| 新产品销量 | actual / target × 100 | target为月度计划目标 |
| 客户审核通过 | actual / target × 100 |目标为月度审核计划 |
| 战略协议/AI项目 | actual / target × 100 | 目标为月度计划 |
