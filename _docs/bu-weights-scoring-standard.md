## 三、统一达成率计算公式（各BU共用）

```
收益类达成率 = actual / target × 100         （cap 120%）
成本类达成率 = target / actual × 100         （cap 120%）
环比达成率   = curr / prev × 100             （cap 120%）
得分(0-100)  = min(100, 达成率)
```

### 综合评分（加权平均）

```javascript
// radar_detail_*.html（各子页面）
var wts = BU_WEIGHTS_{BU};
var score = Math.round(vals.reduce((a, b, i) => a + b * wts[i] / 100, 0));

// radar_hub.html
var wts = BU_WEIGHTS[buId] || DEFAULT_WEIGHTS;

// index_v3.html
if (bd.weights) {
    score = Σ dims[di] × bd.weights[i] / 100;
} else {
    score = Σ dims[di] × DIMS[di].weight;  // 默认统一权重
}
```

## 八、添加/更新BU权重设计流程

1. **分析行业属性**：制造型 / 销售型 / 资源型 / 分销服务型 / 基建期？
2. **识别KSF**：该行业的关键成功因素 → 找出权重最高的维度
3. **识别风险点**：最大运营风险 → D5 权重参考
4. **设计权重**：
   - 制造型：运营效率 D3 权重最高
   - 销售型：经营效益 D2 或技术创新 D4 权重最高
   - 资源型：战略执行力 D1 + 经营效益 D2 权重并重
   - 基建期：风险合规 D5 权重最高
   - 分销服务型：经营效益 D2 + 战略执行力 D1 权重最高
5. **同步修改三个文件**：
   - `radar_detail_{bu}.html`：加 `BU_WEIGHTS_{BU}` 常量 + `renderScoreOverview()` 改加权
   - `radar_hub.html`：`BU_WEIGHTS` 对象加条目
   - `index_v3.html`：`BUS_DATA[buId]` 加 `weights:[...]` 属性
6. **更新本文档**：补全新BU的权重说明
