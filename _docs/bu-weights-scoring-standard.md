## 一、权重体系总览

不同行业的事业部使用不同的权重，体现各自的核心成功因素（KSF）：

| 维度 | SDMD 山东美多 | FELT 法恩莱特 | LHY 润滑油 |
|------|-------------|--------------|-----------|
| D1 战略执行力 | 18% | 15% | 18% |
| D2 经营效益 | 18% | 20% | 22% |
| D3 运营效率 | **20%** | **22%** | 15% |
| D4 技术创新力 | 15% | 18% | **22%** |
| D5 风险合规 | **18%** | 15% | 15% |
| D6 组织活力 | 11% | 10% | 8% |

**权重设计逻辑：**
- **SDMD（电池回收）**：重资产运营+政策驱动，运营效率（D3）和风险合规（D5）是生命线，权重最高
- **FELT（电解液制造）**：制造型+资本密集，运营效率（D3）和经营效益（D2）是核心，权重最高
- **LHY（润滑油）**：品牌销售驱动，经营效益（D2）和技术创新（D4）是竞争力，权重最高

## 二、综合评分计算公式

### 2.1 统一达成率计算（各BU共用）

```
收益类达成率 = actual / target × 100         （cap 120%）
成本类达成率 = target / actual × 100         （cap 120%）
环比达成率   = curr / prev × 100             （cap 120%）
得分(0-100)  = min(100, 达成率)
```

### 2.2 综合评分（加权平均）

```javascript
// 各 radar_detail_*.html 文件
var score = Math.round(vals.reduce((a, b, i) => a + b * wts[i] / 100, 0));
// 其中 wts = BU_WEIGHTS_{BU}，如 SDMD = [18,18,20,15,18,11]

// index_v3.html
if (bd.weights) {
  score = Σ dims[di] × bd.weights[i] / 100;
} else {
  score = Σ dims[di] × DIMS[di].weight;  // 其他BU用默认权重
}
```

## 三、SDMD（山东美多）权重详情

### 3.1 权重配置
```javascript
const BU_WEIGHTS_SDMD = [18, 18, 20, 15, 18, 11];
```

### 3.2 维度说明

| 维度 | 权重 | 行业背景 |
|------|------|---------|
| D1 战略执行力 18% | 收入达成、利润达成、成本控制、回款率 | 回收业务收入和利润是战略基础 |
| D2 经营效益 18% | 碳酸锂销量、修复LFP交付、磷铁液交付、元明粉 | 四大产品线销量是经营核心 |
| D3 运营效率 **20%** | 投料、产出、磷铁液产出、加工成本 | 重资产运营，产线效率决定成本竞争力 |
| D4 技术创新力 15% | 在研课题、MCU项目、MCU降本、技改 | 电池回收技术重要性低于运营 |
| D5 风险合规 **18%** | 隐患整改、安全教育、排查隐患、应急演练 | 环保+安全是回收行业的生死线 |
| D6 组织活力 11% | AI立项、企业荣誉、IATF审核、5S | 组织建设权重最低 |

### 3.3 5月 dims 验算（{90,90,82,80,90,78}）

- 加权分：90×18%+90×18%+82×20%+80×15%+90×18%+78×11% = **86**
- 均分（旧）：85

## 七、添加第4个BU的权重设计流程

1. **分析行业属性**：制造型/销售型/资源型/服务型？
2. **识别KSF**：该行业的关键成功因素是什么？→ 找出权重最高的维度
3. **识别风险点**：该行业的最大运营风险是什么？→ D5/D6 权重参考
4. **设计权重**：
   - 制造型：运营效率 D3 权重最高
   - 销售型：经营效益 D2 或技术创新 D4 权重最高
   - 资源型：风险合规 D5 权重最高
5. **同步修改三个文件**：
   - `radar_detail_{bu}.html`：加 `BU_WEIGHTS_{BU}` 常量 + `renderScoreOverview()` 改加权
   - `radar_hub.html`：`BU_WEIGHTS` 对象加条目 + `getScore()` 已支持
   - `index_v3.html`：`BUS_DATA[buId]` 加 `weights:[...]` 属性 + `calcTotal()` 已支持
6. **验算**：dims={90,90,82,80,90,78} 时加权分与均分差异
