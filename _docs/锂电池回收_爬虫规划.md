# 锂电池回收数据爬虫自动化规划

## 1. 项目背景

AI Daily Report 首页已上线"锂电池回收"板块，展示11个回收品种的价格走势和累计涨跌幅。目前数据文件 `recycling_data.js` 是手动更新的，需要自动化爬虫每天自动更新数据。

## 2. 爬取目标

### 2.1 数据源
- **网站**: 上海有色金属网 (SMM) 新能源价格页面
- **URL**: `https://newenergy.smm.cn/price/14042-15009`
- **数据格式**: HTML 中嵌入 JSON (`tableData` 数组)

### 2.2 目标品种 (11个)
1. 三元黑粉-三元523极片粉 (产品ID: 202106240003 推测)
2. 磷酸铁锂黑粉-磷酸铁锂极片粉
3. 三元废料-三元铝壳523型
4. 磷酸铁锂废料-废旧磷酸铁锂铝壳电池
5. 正极片-废旧磷酸铁锂动力正极片
6. 正极片-废旧磷酸铁锂储能正极片
7. 三元电池包-三元铝壳5系电池包
8. 钴酸锂电池包-钴酸锂铝壳电池包
9. 三元电池包-三元软包电池包
10. 铝箔-铝粉
11. 铜箔-铜粉

### 2.3 数据字段
- `product_name`: 产品名称
- `spec`: 规格
- `unit`: 单位 (元/吨)
- `low`: 最低价
- `high`: 最高价
- `average`: 均价
- `renew_date`: 日期 (YYYY-MM-DD)

## 3. 技术方案

### 3.1 爬虫实现方式

**方案A: 解析HTML中的JSON (推荐)**
- SMM页面使用Next.js框架，数据以JSON格式嵌入在 `<script>` 标签中
- 通过正则表达式提取 `tableData":[...]` 之间的JSON数据
- 优点: 不需要模拟浏览器，速度快，资源消耗低
- 缺点: 如果SMM改版，正则可能失效

**方案B: 使用浏览器自动化 (Playwright)**
- 使用 agent-browser 或 playwright-cli 打开页面，等待JavaScript渲染
- 从渲染后的页面提取数据
- 优点: 更稳健，不受页面结构变化影响
- 缺点: 资源消耗大，速度慢

**推荐方案A**，因为数据直接嵌入在HTML中，无需JavaScript渲染。

### 3.2 技术栈
- **语言**: Python 3.13+
- **依赖库**:
  - `requests` (HTTP请求)
  - `json` (JSON解析)
  - `re` (正则表达式)
  - `datetime` (日期处理)
- **环境**: WorkBuddy managed Python environment

### 3.3 数据存储方案

**方案A: 直接更新 recycling_data.js (推荐)**
- 爬取数据后，直接更新 `recycling_data.js` 文件
- 保持现有数据结构不变
- 优点: 首页无需修改，直接生效
- 缺点: 需要精确替换JavaScript代码

**方案B: 生成JSON文件**
- 爬取数据后，生成 `recycling_data.json` 文件
- 修改首页逻辑，从JSON文件加载数据
- 优点: 数据文件更清晰，易于版本控制
- 缺点: 需要修改首页代码

**推荐方案A**，保持现有架构不变。

### 9.3 爬虫脚本伪代码
```
1. 发送HTTP GET请求到 https://newenergy.smm.cn/price/14042-15009
2. 从HTML中提取 tableData JSON数组
3. 遍历products数组，提取每个产品的价格数据
4. 将SMM数据格式转换为recycling_data.js格式
5. 读取现有recycling_data.js文件
6. 更新或追加最新日期的数据
7. 写回recycling_data.js文件
8. 记录日志，发送通知
```
